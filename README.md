# Every Merge, Measured

A checkable record of my contributions to [career-ops](https://github.com/career-ops-hq/career-ops), an open-source AI job-search agent: merged pull requests, the maintainer's own words, and what I could not verify.

**Read it here: https://artemtrofymenko.github.io/open-source-record/**

The page is the single `index.html` in this repository, served by GitHub Pages. Every figure on it links to the thread where it can be checked, and the page carries its own "Last checked" date, so the numbers live there rather than in this README.
